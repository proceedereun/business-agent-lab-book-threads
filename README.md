# 생각·질문 기록 에이전트

![펜을 턱에 대고 생각하는 사람](thinking.svg)

책을 읽으며 떠오른 생각은 그대로 남기고, 질문은 다음 책까지 이어 갑니다.

```
- 나: 생각하지 않고 살다보면 그냥 환경에 적응하면서 흘러가게 되니까
  - Claude: 왜 "환경에 적응하면서 흘러가게" 된다고 생각해? (고른 이유: …)
    - 나: 생존을 해야 하니까
```

AI는 "왜?"만 묻고, 내 답은 고치지 않고 적습니다.

## 시작하기

```bash
git clone https://github.com/proceedereun/business-agent-lab-book-threads
cd business-agent-lab-book-threads && claude
```

| 명령 | 하는 일 |
|---|---|
| `받아 적기` | 내가 확인한 밑줄·메모를 책 노트에 그대로 옮김 |
| `/chain 책 제목` | "왜?"만 물음. 멈춘 "왜"는 질문 노트로 |
| `/review 책 제목` | 내가 못 본 흐름, 이전 책·질문 노트와의 연결을 근거와 함께 제안. 채택은 내가 함 |
| `점검` | 내 말이 바뀌지 않았는지 등 14가지 검사 |

옵시디언으로 `sample-vault/`를 열면 연결이 그래프로 보입니다.

## 왜 만들었나

다 읽고 던진 질문은 다음 책을 펴면 잊힙니다. 정리를 AI에 맡기면 내 생각이 사라집니다. 그래서 생각은 내가, 받아 적기·묻기·연결 찾기는 AI가 합니다.

## 테스트

스킬을 고칠 때마다 고정 케이스 5개를 다시 돌려 예/아니오로 판정합니다(`tests/`).

## 회고

**잘 된 것**
- 두 번째 책 검토에서 첫 책의 질문 노트 2개가 돌아와 답이 쌓임
- AI가 "본능을 역행해야 성공"과 "동물적인 감각"의 당김을 짚음
- 시험에서 찾은 빈틈을 검사로 막고, 그 검사가 실제 빈틈을 잡음

**막힌 것**
- 첫 실사용 6/8: 질문에 AI의 해석이 섞임 → 규칙을 고쳐 11/11
- 생각을 다시 타이핑하는 수고 → 형광펜 초안 파일로 한 번에
- 내 말만 믿고 AI가 대조 없이 질문을 지움 → 되돌리고 실패로 기록
